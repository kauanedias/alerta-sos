# AlertaSOS

Aplicativo mobile desenvolvido em React Native para auxiliar pessoas em situações de emergência.

O projeto nasceu da necessidade de oferecer uma forma rápida de solicitar ajuda, inspirado em uma situação vivida na minha família.

## Tecnologias

- React Native
- Expo
- Expo Router
- JavaScript
- React Native SVG
- React Native Reanimated

## Funcionalidades

- Splash Screen animada
- Onboarding
- Login
- Cadastro
- Botão SOS
- Compartilhamento de localização
- Histórico de acionamentos
- Perfil de saúde
